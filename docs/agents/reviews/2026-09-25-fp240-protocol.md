## The idea

**LEAD.** Spot. The coin-margined eight-day return ending yesterday is strictly above spot's eight-day return ending yesterday. Buy the next spot open and sell it five days later. The coin-margined book is a signal, not a second leg. Both returns have already closed. The entry open is not an input. One spot leg. It is not a one-day trade and it is not an overnight trade. Funding cash is not added.

The null is that same five-day spot long on every in-screen day the two opens exist. The lead filter is off.
