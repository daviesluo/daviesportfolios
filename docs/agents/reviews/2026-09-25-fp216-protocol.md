## Costs, window, null

Ten basis points a side on each leg. One hundred dollars stands on the
long leg and one hundred dollars stands on the short leg, so the dollar

spread is added on this screen. Funding cash is not added. Entries in

is not filled in. The null is 200 draws, seed `20250925`, index 190, of

The null is the same session spread, long the more negative residual and short the more positive one, on every in-screen day the two residuals differ. The opposite-sign filter is off. It is not an unconditional long and not an unconditional short.

## The idea

**SCM.** On day D, strictly before 2023-12-31, spot's close/open minus the mark's close/open, and the coin-margined perpetual's close/open minus the same mark close/open, have opposite signs. A zero residual is neither positive nor negative. An equal pair does not fire. This is a different pair and a different hold from the spot-versus-USDT residual. A day with no coin-margined session bar is not a trade and is not filled in.

The next session is long the more negative residual and short the more positive residual, each from the open to the close. The signal day's close is not the fill. Funding cash is not added.

A count taken before this freeze, with no profit computed, was 143 days that had both an opposite-sign pair and a coin-margined session to trade. The rule is not widened if the scored count differs and stays at least 30. If it is under 30, the rule fails as written.
