## Costs, window, null

Ten basis points a side on the one leg. One hundred dollars stands on
that leg. No second leg is opened and no further spread is added.
Funding cash is not added. Entries in `[2023-01-01, 2024-01-01)` UTC.
An exit may be the 2024-01-01 open when the hold reaches that day. That
open is not an entry and not a signal. A day with no print is not a
print and is not filled in. The null is 200 draws, seed `20250925`,
index 190, of the single-leg payoff named below. A pass is at least 30
trades, mean net above zero, and mean net above that null.

The null is the same seven-day coin-margined short on every in-screen day on which both seven-day returns exist, including a week that led and a flat week. The lag filter is off. It is not a one-day short and the USDT book is not a second leg.

## The idea

**CMS.** BTCUSD_PERP, one coin-margined leg. Compare that book's close-to-close return over the seven days that have already finished with the USDT perpetual's return over the same seven days. If the coin-margined return is strictly lower, sell the next coin-margined open and buy it back seven days later. An equal pair does not fire. The USDT closes are a signal only. A USDT open is not a fill. The hold is seven days, not one day and not overnight. Funding cash is not added.

The pool is that seven-day short on every day both returns exist, so the lagging book is a subset. A day with no coin-margined bar is not filled in.

A count taken before this freeze, with no profit computed, was 171 days. The pool was 346 days. The rule is not widened if the scored count differs and stays at least 30. If it is under 30, the rule fails as written.
