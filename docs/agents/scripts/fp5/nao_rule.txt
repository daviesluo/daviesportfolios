Spot cannot short. Long or flat. Books: BTC and ETH, both driven by this index.
Series: NOAA CPC daily NAO, file norm.daily.nao.index.b500101.current.ascii. The series starts 1950-01-01. The index is signed, so the change is a difference, not a ratio. A missing print is not a level. A line that is not four fields, including a stuck -99 sentinel, is not a level. A weekend is a level. A missing day is not filled from the previous session.
Change = index[D] - index[previous calendar day]. Missing unless the previous calendar day exists.
Sort the previous 90 printed differences ascending. The threshold is the 72nd (1-based), index 71.
Long the next UTC calendar day when that difference is strictly above the threshold.
A day whose previous calendar day has no difference is not an execution day. The signal is not carried forward.
Execution days are 2018-01-01 through 2018-12-31. Both spot books start 2017-08 and the index is complete through 2017, so 2018 is the first January with 90 earlier differences and both books. No other year is scored.
Prices are Binance spot daily closes (BTCUSDT, ETHUSDT). The long day earns that day's close over the previous close.
Cost 20 bps on each change from flat to long and 20 bps on each change from long to flat.
A position still long on the last screen day is charged the exit that day and earns no further return.
Stress doubles each charge. A loss kills the family. A gain is not a pass: these are daily closes, not prints through a price.
Screen only: 2018. No other year is scored.
